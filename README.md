# mi-primer-proyecto-conexion-cliente-servidor-linux-windows
repositorio en el que se realizara la prueba de creación de mi primer proyecto en GitHub

## DESCRIPCION DEL PRYECTO 
proyecto de conexión de maquina virtual de Linux a Windows de tipo cliente-servidor que permite enviar mensajes, ver estado de la maquina que actúa de servidor, ejecutar comandos que se mandan desde el cliente al servidor.
